# AndroidWorld 完整轨迹包

[下载压缩包](androidworld-traces.zip) · [逐题索引](TRACE-INDEX.json)

压缩包包含 113 道通过题目的轨迹，以及剩余三题各自最新且已有官方评分的失败轨迹。共 116 个任务目录、1,022 张截图和 669 份外置回执。

保留目标、提示词、完整调用、工具回执、模型总结、诊断、操作时间线和官方评分。不包含录像；构建版本和哈希信息已脱敏。外置回执已展开为 JSON，相关引用指向包内文件。

解压后，通过轨迹位于 `traces/passed-113/`，三题失败轨迹位于 `traces/not-passed-3/`。
